## 🎯 Características

- ✅ **Portada interactiva** con buscador en vivo
- ✅ **Banderas SVG/PNG** de alta calidad (vía flagcdn.com)

- ✅ **Sin build** — abrir y usar
- ✅ **GitHub Pages** — hosting gratuito
- ✅ **Navegación fluida** entre traductores
